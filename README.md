# Aatera - IT Management Platform

A comprehensive IT management platform built with Django REST Framework and Next.js.

## Project Structure

- `/backend` - Django REST Framework backend
- `/frontend` - Next.js frontend

## Tech Stack

### Backend
- Python
- Django REST Framework
- PostgreSQL
- Celery
- Redis
- Channels (WebSocket)

### Frontend
- Next.js
- TypeScript
- TailwindCSS
- Redux Toolkit
